03 / SERVER CONFIGURATION

Where credentials belong

Keep provider secrets in the local server-side .env file. Do not paste API keys into this page, commit them to Git, or expose them in frontend code.

HONEYCOIN_ENVIRONMENT=Sandbox
HONEYCOIN_API_BASE_URL=
HONEYCOIN_API_KEY=
HONEYCOIN_PUBLIC_KEY=

PAYCREST_API_BASE_URL=https://api.paycrest.io
PAYCREST_API_KEY=
PAYCREST_API_SECRET=

A configured status means required values are present; it does not prove that the provider has approved your account or enabled a corridor. Use the readiness refresh and rate preview to test the available read-only access.
