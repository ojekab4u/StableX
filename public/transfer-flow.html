5. Paytrie customer transaction

StableX supports two separately controlled Paytrie paths. The restricted personal test is available only to the single StableX PERSONAL account configured by the operator. Canadian customers use the standard onboarding path.

Restricted personal-account test

Enter the email address of the authorised existing Paytrie account. Paytrie sends its one-time code to that mailbox; the account holder must provide the code to the person operating this test. This does not enable Paytrie for other StableX customers.

Base Mainnet receiving wallet

USDC is delivered to the Base wallet saved against this StableX test account. If no wallet is linked, connect the authorised receiving wallet below.
